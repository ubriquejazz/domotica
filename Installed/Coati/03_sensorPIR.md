# 3. PIR Motion Detector

## 3.1 Operating Principle

The PIR (Passive Infrared) detector identifies movement by detecting changes in infrared radiation within its field of view.

For example, when a person moves through the monitored area, the resulting infrared changes are detected by the sensor.

When movement is detected, the PIR transmits a wireless signal to the Coati central unit.

## 3.2 Initialisation

After inserting the batteries, the PIR detector requires approximately **60 seconds** to initialise.

During this period, allow the sensor to stabilise before attempting to register it with the central unit.

## 3.3 Registering the Sensor

To register the PIR detector:

1. Insert the batteries.
2. Wait 60 seconds for the sensor to initialise.
3. Set the central unit to sensor ID learning mode (`security code + *`).
4. Press and hold the PIR detector's Sabotage Switch (SW) for more than three seconds.
5. The sensor transmits its ID code to the central unit.
6. A long beep from the central unit confirms successful registration.

## 3.4 Operation

Once registered, the PIR detector monitors its field of view.

When movement is detected, it transmits a radio signal to the central unit.

The central unit responds according to its current operating mode.
