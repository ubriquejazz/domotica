# 4. Magnetic Door and Window Detector

## 4.1 Operating Principle

The magnetic contact detector is designed to monitor the opening of doors and windows.

It consists of a detector and a magnetic element. When the magnet is separated from the detector, a wireless signal is transmitted to the Coati central unit.

The detector can therefore be used to monitor access points such as windows or entrance doors.

Before permanently installing the detector, check that reliable radio communication with the central unit is possible.

## 4.2 Initialisation

1. Insert the battery.
2. Wait approximately 10 seconds for the detector to stabilise.

## 4.3 Registering the Sensor

To register the magnetic detector:

1. Insert the battery and wait 10 seconds.
2. Set the central unit to sensor ID learning mode (`security code + *`).
3. Press and hold the detector's Sabotage Switch (SW) for more than three seconds.
4. The detector transmits its ID code to the central unit.
5. A long beep confirms successful registration.

## 4.4 Operation

Once installed and registered, the detector monitors the separation between the magnetic element and the detector.

The following events generate a wireless signal:

**Opening the battery cover**

Opening the battery cover activates the Sabotage Switch, causing the detector to transmit a signal to the central unit.

**Opening a protected door or window**

When the magnet is separated from the detector, a radio signal is transmitted to the central unit.

The central unit responds according to its current operating mode.
